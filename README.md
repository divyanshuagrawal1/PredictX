# 🤖 PredictX — AI-Based Predictive Maintenance

PredictX is an AI-powered predictive maintenance system that analyzes machine operating parameters and predicts the probability of machine failure before it occurs.

The project uses machine learning models trained on the AI4I 2020 Predictive Maintenance Dataset and provides an interactive Streamlit dashboard for real-time prediction.

---

## 🚀 Features

- Machine failure prediction using XGBoost
- Failure probability estimation
- Custom prediction threshold
- Low / Medium / High risk classification
- Maintenance recommendations
- Historical normal-range comparison
- Feature status analysis
- XGBoost feature importance visualization
- Model performance radar chart
- Interactive Streamlit interface
- Saved ML model and preprocessing pipeline
